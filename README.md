# WebXR MR Drumset

A Mixed Reality drumset built with WebXR and Three.js, featuring a Node.js WebSocket-to-OSC bridge and internal audio synthesis.

## Build and Run

1. **Install Dependencies**:
   ```bash
   npm run install:all
   ```

2. **Start the Servers**:
   ```bash
   npm start
   ```

## Play

1. Put on WebXR compatible headset.
2. Connect headset to the network.
3. Check terminal output for link (`https://"local ip":5173`).
4. Open the Browser (on headset) and navigate to URL. 
5. Enter **AR / Immersive mode**.
6. Use controllers as drumsticks.
7. Profit??

## Controls
- Swings: Hit floating drum kit with drumsticks.
- **Right Trigger:** Bass / Kick Drum
- **Left Trigger:** Hi-Hat Pedal
